# gchat-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `gchat-export` into `gchat-mcp`: an MCP server that reads the local Google Chat SQLite store, plus the existing downloader kept as a CLI that the server's `sync` tool runs as a subprocess.

**Architecture:** One Python package `gchat_mcp` (src layout, like `_MCP/outlook-mcp`). The CLI (`python -m gchat_mcp.cli`) is today's `gchat_export.py` split into modules, minus Markdown. The server (`python -m gchat_mcp`) reads SQLite directly through `queries.py` and never imports Google code; its `sync` tool runs the CLI as a child process with a timeout.

**Tech Stack:** Python 3.11, `mcp>=2` (`mcp.server.mcpserver.MCPServer`), `google-api-python-client`, `google-auth-oauthlib`, sqlite3, pytest.

**Spec:** `docs/superpowers/specs/2026-11-10-gchat-mcp-design.md` (read it and `_MCP/outlook-mcp` — `CLAUDE.md`, `src/outlook_mcp/server.py`, `safety.py`, `dates.py`, `tests/test_server.py`, `tests/test_feature_map.py` — before Task 1).

## Review Focus

2. **Local-midnight boundaries and fractional seconds** → `since="2026-10-01"` in UTC-3 must include `2026-10-01T03:00:00.500Z` and exclude `2026-10-01T02:59:59Z`. Test in Task 2.

4. **Injected closing tag in chat text** → a message containing `</untrusted_chat_content>` must not end the wrapper. Test in Task 2.
5. **Ambiguous or unknown `space`** → error listing up to 10 matching titles, never silently picking one; exact title match wins. Test in Task 2.

**Interfaces:**
- Produces `runner.CliResult(code: int, stdout: str, stderr: str)` (dataclass) and `runner.run_cli(args: list[str], timeout: int, cmd: list[str] | None = None) -> CliResult`; default `cmd = [sys.executable, "-m", "gchat_mcp.cli"]`; always `--non-interactive --json` appended by the tool, not here. - Server tool `async def sync(month: str | None = None) -> str`: builds args (`["--non-interactive", "--json"]` + `["--month", month]`), runs `runner` via `asyncio.to_thread`, timeout `SYNC_MONTH_TIMEOUT` if month else `SYNC_TIMEOUT`. Results:
  - exit 0/2 → `wrap_untrusted` JSON `{seq, messages_changed, messages_deleted, spaces, no_access}` from the child's stdout (wrapped because `no_access` carries space titles).

  - exit 1 or unparsable stdout → `ToolError` with the last 5 lines of stderr.
  - timeout → `ToolError("sync timed out after N s; the download was stopped.")`
- Annotations: `readOnlyHint=False, destructiveHint=False, idempotentHint=True, openWorldHint=True`.
